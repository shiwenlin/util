# util

淘宝个护家清（身体护理 / 衣物洗护 / 家庭清洁）**商品标题 + SKU 搜索标题**生成工作台与规则库。

## 核心交付

| 文件 | 说明 |
|---|---|
| `workbench/个护家清标题工作台.html` | 主交付物。单页离线 HTML，双击浏览器打开即用，无需构建、无外部依赖 |
| `淘宝标题与SKU规则手册_2026版.md` | 2026 淘宝标题 / SKU 搜索标题规则（【官方】与【行业】分开标注） |
| `taobao_title_workbench_PRD_v1.md` | 工作台产品需求文档 |
| `SOP差异对照与工作台验收报告.md` | 用户自有 SOP vs 规则手册的差异对照与验收 |
| `research_蓝月亮手洗专用洗衣液.md` | 真实单品研究样例（联网检索结果） |
| `overview.md` | 版本演进与功能总览 |

## 工作台能力

- **商品标题**：60 字符 / 30 汉字口径，多套候选，点击「选用并复制」
- **SKU 搜索标题**：非 3C 口径 ≤30 字符 / 15 汉字，每 SKU 输出 **主推 1 条 + 备选 3 条**（场景人群路 / 热搜长尾路 / 时段卖点路），点击即复制
- **词池**：卖点 / 人群 / 场景三类分池，按搜索价值排序（热搜词 > 商品名自带 > 研究回填 > 品类内置），每池硬上限 20，超出直接舍弃；任一词可删除 = 全局屏蔽
- **合规三档分级**：🔴 硬性违禁（强制替换）/ 🟡 资质条件词（默认保留并标注需资质）/ 🟢 安全词
- **真实性校验**：严格模式下 SKU 标题用词必须溯源到该 SKU 规格名、研究回填词或已勾选词；10 组互斥属性自动判冲突

## 测试

```bash
cd workbench
node _smoke3.js        # 解析引擎回归（洗衣液 6 SKU）
node _t10.js           # 1~10 SKU 压测（宽松）
node _t10s.js          # 1~10 SKU 压测（严格）
node _strictcheck.js   # 严格模式 + 互斥属性用例
node _sopcheck.js      # 用户 SOP 案例验收
node _altcheck.js      # 备选题三条词路验收
node _copycheck.js     # 复制交互结构验收
node _blockcheck.js    # 删除屏蔽验收
node _shrinkcheck.js   # 删除不补位验收
node _capcheck.js      # 词池排序与硬上限验收
node _clscheck.js      # 卖点/人群/场景 归类验收
node _layoutcheck.js   # 双栏固定 / 拖拽调宽 / 回顶按钮 / 预填值清空 验收
```

`workbench/_patch_*.py` 为历次迭代的补丁脚本，保留作变更留痕。
